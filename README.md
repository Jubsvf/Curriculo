# 📄 Currículo Online v1.0

Este repositório contém a versão 1.0 do meu Currículo Online, desenvolvido como uma vitrine profissional para o mercado de trabalho e para a comunidade acadêmica. O projeto une a estruturação semântica do HTML, a estilização ágil do Bootstrap e a interatividade do JavaScript.

## 🎯 Sobre o Projeto

O objetivo desta página é apresentar um perfil profissional completo de forma moderna e acessível. A página funciona como um portfólio digital, detalhando um breve resumo pessoal, habilidades, formação acadêmica e experiências profissionais.

## 🚀 Funcionalidades

O projeto atende a todos os requisitos técnicos propostos na atividade:

*   **Perfil Dinâmico:** Foto de perfil importada via URL (LinkedIn/GitHub) com estilização arredondada (`rounded-circle`).
*   **Cabeçalho Profissional:** Apresentação com nome e cargo/curso atual.
*   **Seções de Conteúdo:**
    *   *Sobre mim:* Resumo da trajetória profissional e acadêmica.
    *   *Habilidades:* Listagem de conhecimentos técnicos (utilizando componentes do Bootstrap, como barras de progresso ou listas estilizadas).
    *   *Contato:* Links reais e funcionais para E-mail, LinkedIn e GitHub.
*   **Interatividade (JavaScript):** Implementação de um botão de **Modo Noturno (Dark Mode)**, permitindo a troca dinâmica das cores de fundo e texto da página.

## 🛠️ Tecnologias Utilizadas

*   **HTML5:** Estruturação semântica de todo o conteúdo da página.
*   **Bootstrap:** Framework CSS utilizado para garantir um layout profissional, responsivo e com componentes pré-estilizados.
*   **JavaScript:** Responsável por trazer "vida" à página, manipulando o DOM para a funcionalidade de troca de tema (Dark Mode).
